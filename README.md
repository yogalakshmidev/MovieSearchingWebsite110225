# Movie Searching Website Using React
## Description:
1. In this, we use the OMDB API to fetch the movies
2. Implement the Search bar functionality for the users to enter the movie name or details
3. Each movie that are shown in the list is having the detailed view by clicking on the image or the Read More button
4. In this, Pagination concept is also done... By clicking the NEXT and BACK button available on the bottom of the movie list.
5. We can also choose the movie based on the types in the drop down filter that are available in the api url.
6. We use React Router for the navigation from one link to another.
7. Page not found page is displayed when the user enter the wrong url.
